# Geradores históricos preservados, fora da suíte ativa

Estes dois arquivos foram movidos sem modificar seus bytes. Geravam artes/conceitos e incluíam pressupostos de animação dirigida pelo gabarito e esperas sem limite. Não são testes aprovados da nova física. Mantê-los aqui evita que `testDebugUnitTest` execute geradores antigos como se validassem o jogo atual. Os testes de resultado físicos, de integridade numérica, de apresentação e de interação real no Android permanecem ativos.
